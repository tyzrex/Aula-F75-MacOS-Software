# Changelog

## 0.2.0
- Renamed from "AULA Hub" to **Keylume** (not affiliated with AULA). Backups from the old name are carried over.
- Bluetooth and 2.4G (read-only) connections, with Mac/Windows key legends and Mac mode.
- Redesigned app: overview, lighting, per-key, live, remap, device, backups panes.
- Per-key undo/redo (⌘Z / ⇧⌘Z), menu bar quick controls, Copy Diagnostics, first-run guide on the connect screen.
- Battery is hidden on the cable, where the keyboard reports a meaningless 0 %.
- GitHub Actions build + self-test workflow.

## 0.1.0
- Initial wired support: effects, palettes, per-key colors, themes, key remap, backups, CLI.
